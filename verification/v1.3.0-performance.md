# Mognitio 1.3.0 resource acceptance

All 21 frozen cells passed. Each cell ran one warm-up followed by five measured
compilations using the same compiler image. Every compilation and all three
runtime argument observations per output were correct. No sample was dropped
or replaced and no formal cell required a retry.

The per-cell median is at most 30 seconds and maximum measured peak RSS is at
most 256 MiB. Every invocation has an independent 120-second timeout.
The budget applies to these fixed cells, not arbitrary input size.
Nesting depth 128 and cardinality 1,000 are test dimensions, not language caps.

## Environment and scope

Intel Core i9-10850K, Ubuntu 26.04.1, Linux 7.0.0-38-generic, non-root,
executable tmpfs, umask 0022, no default ACL, powersave governor.
[Environment observations](v1.3.0-environment.json) include memory, CPU affinity,
resource limits, swap, load and timing. Regression and focused jobs completed
before the sequential run.

Wall time uses a monotonic clock from process launch through termination.
Peak RSS is each child compiler's wait4 maximum resident set, converted from
Linux KiB to bytes. The runner does not sum its own memory, generated-program
memory or cumulative child usage. Seed build and generated-program execution
are excluded from compile time; all startup, source reading, checking,
generation, publication and process exit are included.

## Earlier failures and necessary changes

The initial complete implementation exceeded the 120-second timeout on the
combined fixture. Intermediate one-sample comparisons remained above budget.
[Preliminary observations](v1.3.0-preliminary.json) retain those unsuccessful
samples, later experiments and their compiler identities. They are not formal
acceptance runs and were not substituted into the final median.

The resulting internal changes reduce allocation and repeated traversal:
bounded scalar chunks with shared ASCII constants, lazy Unicode tables,
joined token fragments, cached CFG predecessors and batched definition sets,
combined opcode/field records, bucketed label lookup, and output selection for
helpers reachable from main after every function has been checked.
Neither source semantics, fixture dimensions nor the numerical budget changed.

[Supplemental diagnostics](v1.3.0-diagnostics.json) separately record ASCII,
repeated non-ASCII and diverse 2/3/4-byte comments, plus instrumented phase
timestamps and arena/label counts. These observations do not replace the
unmodified compiler measurements above.
