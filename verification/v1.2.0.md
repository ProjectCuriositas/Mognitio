# Mognitio 1.2.0 implementation verification

The implementation adds integer value parameters, distinct checked fixed-width
integers, Bits, immutable Bytes, endian conversion, and new-file binary
publication. Ordinary Int and existing text/directory I/O retain their 1.x
contracts. This record describes implementation acceptance, not a release.

## Coverage and commands

The [75-case manifest](v1.2.0-conformance.json) maps every acceptance ID to its
fixtures. There are 72 current requirements and three future 2.0 Alpha gates.
C120-E06 is structural N/A for the inspected implementation/kernel, with
[ownership and kernel-source evidence](v1.2.0-publication-profile.md).
A manifest entry alone is not a passing execution result. Exact candidate
identity and cumulative results belong to the integration pull request.

Run the complete compiler/CLI suite:

```sh
sbcl --noinform --script scripts/test.lisp
sha256sum -c verification/SHA256SUMS
git diff --check
```

Numeric verification exhausts 174,760 small-width operand pairs, checking each
legal arithmetic result against mathematical Int calculations and Python-derived
counts/sums. Bitwise results use an independent binary-digit calculation.
Every small-width value also exercises legal negation, complement, and every
valid shift/index count. Invalid counts and conversion boundaries are separate
cross-entry fixtures; aliases forward literal obligations through two templates.
Widths 9 through 64 use every width's range and sign-bit boundaries and 2,128 seeded values
(seed 1202026), including the full unsigned 64-bit upper range. Fatal overflow,
zero division, static rejection and unreachable expressions are separate cases.

Bytes checks cover fixed endian vectors, invalid constructor elements, snapshot
retention, GC, length/allocation failures and raw file contents. Publication
checks cover evaluation order, ordinary Function/try handling, non-executing
frontends, protected inputs/artifacts, ACL/umask, short writes, synchronized
commit races, raw error observations and result allocation failure.
Artificial lost-profile/uncertain-reply tests are distinct from filesystem
atomicity evidence.

## Independent executable workload

The [Mognitio emitter](../examples/binary-emitter/README.md) builds ELF fields
and branch displacements from runtime payload length. The independent Python
oracle defines the complete expected image, rather than accepting backend
agreement. Two payloads times exit 0/7 run in both backends, repeated with new
paths. Data and Executable preserve identical content.

Additional isolation:

```sh
python3 tests/v120-emitter.py --userland ROOT24 --userland ROOT26 --evidence RESULT.json
```

Prepared Ubuntu Base 24.04.5 and 26.04.1 amd64 userlands share the certified
Linux kernel. They run non-root with umask 0022, no default ACL, executable
tmpfs, and no SBCL, Mognitio Compiler, C compiler, assembler or linker.
The host supplies only the immutable emitter and output directory. No output
chmod or patch is allowed. This is a userland matrix, not two independent
distribution kernel certifications.

## Consumer and performance gates

Lévi at 0b11655172c636bb44c856dc3469a99b33f1071c is checked without product edits,
using its verify.py and regression.py against the exact candidate.

Build immutable images with tests/v11-measure-build.py. The full unchanged
74-cell matrix compares the candidate against v1.1.0
4f8c3d69cd123f3952516e47ad605c03743d3ab6 using tests/v120-performance.py.
It preserves relative time/RSS, noise, absolute budgets and retention checks;
it does not demand a second speedup over the already optimized compiler.
tests/v120-improvements.py separately retains all four original speedup
requirements against bf402a477b87792c0c5288cf2bdf484cef4ad107.
Both use one warm-up and five alternating observations, independent output
oracles, source/image identities, and a stable CPU/environment.

All 74 regression cells and four original improvement requirements passed.
Maximum candidate RSS was 3500 KiB; retention growth was 0 KiB in all three modes.
The [sanitized observations](v1.2.0-performance.json) retain every batch, including
two regression cells that required a second batch after noise.

Unsuccessful or noisy batches remain in local evidence. A later batch cannot
erase a wrong result or candidate budget failure. Sanitized final outcomes
and exact identities are recorded after these gates run.

## Support boundary

The certified Linux 7.0.0-38.38 amd64/tmpfs profile supplies evidence for
NotPublished classification; it does not gate execution. Unverified environments
attempt the same no-replace operation and accept success. A failed commit with
no applicable proof reports Unknown. Actual mechanism failures still return a
typed error, without replacement or a weaker fallback. Existing entries remain
protected by the earlier existence check. See the
[portability review](v1.2.0-publication-review.md) for follow-up evidence.
This policy does not change existing text/directory I/O support.

C120-G01 through G03 remain future gates; arbitrary-precision ordinary Int is
not implemented in 1.x. Compiler implementation, client compatibility, release
tag, GitHub Release and APT publication are separate states.
