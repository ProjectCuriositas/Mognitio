# v0.11.0 test acceptance ledger

Each row names a distinct acceptance case and its executable observation.
The exact candidate revision and cumulative results are recorded in the
implementation pull request. Run the [full gate](v0.11.0.md#reproduce);
this table is traceability, not a substitute for that run.

The CLI file includes an independent `covered` set for its case IDs.
Runner-fault cases are intentionally tested through controlled internal
adapters as well as real native processes; they are not exposed as CLI flags.
