# Mognitio 1.3.0 implementation review corrections

Three implementation deviations were reproduced and corrected without changing
the language contract, accepted source profile, design or resource budgets.
The previous acceptance suite had passed but lacked these counterexamples.
Its [original record](v1.3.0.md) and JSON evidence remain historical observations.

## Corrections and counterexamples

| Finding | Previous behavior | Correction |
|---|---|---|
| Function and while body boundary | A function body followed by +1 compiled; equality after a while body was swallowed into the body | Parse the required body block through its closing brace, then resume only the enclosing expression |
| Mixed comparison operators | true == 1 < 2 compiled despite non-associative comparison syntax | All six comparison operators use the same binding power and require explicit grouping when combined |
| Primary type-error span | Invalid initializers and assignment operands pointed at the binding name | Use the incompatible expression span; retain name spans for name and mutability errors |

[The regression runner](../tests/mgnc/review.py) contains 63 independent expected
outcomes: body boundaries, ordinary blocks, all 36 ordered comparison pairs,
12 explicitly grouped comparisons, arithmetic/logical precedence and exact
diagnostic byte ranges plus scalar line/column after Unicode, CRLF and a tab.
The [before record](v1.3.0-review-before.json) has 17 failures on the original
compiler. The [after record](v1.3.0-review-after.json) passes all 63 cases.
Both records preserve complete fixture text and compiler identities.

## Reproduction and delivery boundary

~~~sh
SEED build compiler/mgnc/mognitio.toml -o COMPILER
python3 tests/mgnc/review.py --compiler COMPILER --evidence review.json
~~~

Run the remaining commands in [the test guide](../tests/mgnc/README.md) with the
same fixed compiler, and the regular suite from the repository root.
The compiler remains an explicit source build, outside normal packages and the
normal backend. This correction does not create a tag, release or publication.
