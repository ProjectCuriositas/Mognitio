# v0.11.0 release validation

Date: 2026-10-01

The v0.11.0 specification, design, and implementation are accepted for release.
This is a source release for Linux amd64. The compiler host requires glibc
2.34+, SBCL with bundled ASDF, UIOP, and SB-POSIX. Ordinary generated ELF
executables need neither SBCL nor libc. No prebuilt compiler is distributed.

## Language tests and review fixes

Compiler-defined attributes are declaration metadata. `@test` selects
module-level immutable bindings of type `Function(): Unit`; file and function
names do not select tests. `assert <Bool expression>;` evaluates its operand
once and reports assertion failure separately from panic or static errors.
Assertions also retain their meaning in ordinary run/build artifacts.

`mgn test mognitio.toml` checks all project sources, prepares all test images,
and executes each selected test in a fresh native process. Normal entry
validation does not apply to the test command. Results and summary go to stdout;
failure identity, stage, and assertion location go to stderr. Command failures
stop further attempts while preserving known results and aborted/not_run counts.

The [72-case ledger](v0.11.0-testing.md), [implementation record](v0.11.0.md),
and [runner review fixes](v0.11.0-review.md) record coverage and evidence limits.
Regression tests include parent storage recovery and process/fd ownership,
returning-helper register preservation, and diagnostics after result commit.
Parent storage injection is recoverable fault injection, not actual memory
exhaustion; native program allocation failure retains its own classification.

See the [test guide](../examples/testing/README.md) for syntax, discovery,
output, and exit codes. Use the real compiler `bin` directory on PATH as
described in [usage](../README.md).

## Distribution and limits

Use the tagged source archives. Other hosts/targets and prebuilt compiler
packages are not validated. Parallel execution, filtering, fixtures,
setup/teardown, parameterized or property-based tests, mocking, coverage,
benchmarks, IDE integration, user-defined attributes, and macros are outside
this increment. Backwards compatibility is not guaranteed before v1.0.0.

Infinite tests have no built-in timeout. Broken output sinks or externally
terminated runners cannot guarantee complete reporting or cleanup. Finite
tests do not certify unbounded resources, concurrent filesystem replacement,
or power-loss durability. Existing collector complexity limits remain unchanged.
