# v0.9.0 release validation

Date: 2026-09-28

The v0.9.0 specification, design, and implementation are accepted for release.
This is a source release for Linux amd64. The compiler requires SBCL with
bundled ASDF, UIOP, and SB-POSIX. Generated ELF executables require neither
SBCL nor libc. No prebuilt compiler is distributed.

## Language and execution

The release implements nominal product/sum types, exact aliases, explicit
templates, first-class functions with snapshot captures, persistent Lists,
contract evidence and explicit packaging, Result-based indexing/slicing,
two-axis completion analysis, and host/native execution.

The final surface revision adds value-producing `loop { ... }`, arrow-only
value members, `witness Concrete implements Contract`, and ordinary `_`
identifiers. While/over loops retain Unit results and plain `break;`.
Catchable CL execution allocation failures produce exit 4; compiler allocation
failures remain exit 3. Static diagnostics specify phase, span, and explanation.

[Implementation validation](v0.9.0.md) records independent verification,
resource probes, allocation/publication fault injection, native ABI v5,
root/liveness checks, and persistent-list costs.
[Test coverage](../tests/README.md) maps active fixtures and intentional
migration. Earlier source syntax is not a compatibility interface.

## Distribution and limits

Use the [repository instructions](../README.md) for run and build commands.
Successful builds are silent; generated artifacts print the Boolean result.
The suite exercises 104 named positive programs through CL, ordinary native GC,
and collection before every allocation, along with independent generated
oracles and rejection/mutation cases.

Persistent-list structural complexity excludes allocation, GC, and body work.
The current collector can perform quadratic header visits for a reverse chain;
bounded tests do not claim unbounded resources, OS-kill durability, or every
possible input. Other hosts and targets remain unverified.
