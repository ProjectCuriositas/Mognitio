# Mognitio 1.3.0 experimental compiler acceptance

The independent Mognitio-written compiler builds standalone Linux AMD64 ELF
executables from its scalar source profile. All 55 acceptance conditions passed.
This records implementation acceptance; no release or package publication was
performed.

## Environment and filesystem observations

Non-root Ubuntu Base 24.04.5 and 26.04.1 userlands share Linux
7.0.0-38-generic. They contain no old compiler, SBCL, C compiler, assembler,
linker or Python. Compilation and generated execution run in separate isolated
views. The latter has neither source nor compiler access. Compiler syscall
traces admit only its initial exec.

These are two userland results, not independent distribution-kernel
certifications. The archive identities are retained in the preceding
[1.2 isolation record](v1.2.0.md); current inventory hashes are in the new record.

The CLI tests preserve umask and inherited ACL. The user-owned FUSE noexec
provider rejects atomic no-replace rename, returning a publication error.
The runner separately publishes into its ordinary backing directory, then
observes execution denial through the noexec alias without changing mode bits.
It does not claim successful direct publication on that provider.

Fault injection observes failed reads/writes, precommit close errors, an
uncertain commit with no output, an uncertain reply after a completed commit,
and a cleanup error after publication. Complete or uncertain output is retained.
Injected replies are distinguished from filesystem atomicity guarantees.

## Existing toolchain and consumer

The complete regular suite passed at the final acceptance harness revision:
214 tests, 9,261 assertions and 1,266 processes, followed by every external
suite through ACCEPTANCE_EDGES_OK checks=19. It covers normal run/build/test/lsp,
replacement, previous workload, numeric, binary and publication regressions.
The earlier compiler-source revision also passed the same complete suite.

Lévi at 0b11655172c636bb44c856dc3469a99b33f1071c passed verify.py and all
11 regression negative controls against the compiler-source revision.
No consumer files changed. [Sanitized summaries](v1.3.0-regression.json)
retain execution identities and log hashes.

The regular src, bin, scripts, packaging and VERSION paths are unchanged from
the fixed 1.2.0 source. Its verified installer bundle contains no mgnc.
The new compiler is built explicitly from source and is not selected by the
normal backend or added to regular packages.
