# Mognitio 1.1.0 implementation verification

The native allocator and collector changes preserve the existing language APIs
and immutable-value contracts. Ordinary Mognitio programs now provide the
scanner, text assembly, and persistent symbol-table reference workloads.
See the [runtime record](v1.1.0-runtime.md) for the internal mechanisms.

one warm-up followed by five observations, alternating execution order.

## Reproduction

Use clean checkouts at the revisions above with the prerequisites in
[Verification](README.md). Build each side using the same build helper:

```sh
python3 tests/v11-measure-build.py --compiler BASELINE --levi LEVI --output BASE_IMAGES
python3 tests/v11-measure-build.py --compiler CANDIDATE --levi LEVI --output CANDIDATE_IMAGES
taskset -c 4 python3 tests/v11-measure.py --baseline BASE_IMAGES --candidate CANDIDATE_IMAGES --evidence RESULTS
sbcl --noinform --script scripts/test.lisp
sha256sum --check --status verification/SHA256SUMS
git diff --check
```

Use fresh output directories. Preserve failed and noisy observations; do not
choose the fastest batch or substitute a timeout threshold for elapsed time.

## Limits and completion boundary

Acceptance applies to the fixed inputs and environment, not every machine or
arbitrarily large input. Free-list first-fit, static-reference matching, arena
selection, descriptor dispatch, and linear symbol lookup still have costs.
The symbol workload performs 524,800 name comparisons for 1,024 unique names
followed by a miss. It is not a constant-time symbol-table implementation.

A separate Unicode scanner counter build observed 200,738 free-block visits
at 4,096 scalars and 1,603,226,389 at 16,384. Complete output matched the
normal image and the independent oracle. First-fit search remains a major
source of operations at larger sizes; these counters do not assign wall-time
shares to individual components. The observed process also includes serialization.

The larger-input observations below use single runs beyond the accepted
maximum. They describe a boundary and do not extend the performance guarantee.
