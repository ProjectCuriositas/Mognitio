# v0.13.0 release validation

Date: 2026-10-03

The v0.13.0 specification, design and implementation are accepted for release.
This is a source release for Linux amd64. The compiler host requires glibc
2.34+, SBCL with bundled ASDF, UIOP and SB-POSIX. Ordinary generated ELF
executables need neither SBCL nor libc. No prebuilt compiler is distributed.

## Directory operations

`Std\Io` adds ordinary Function values `joinPath`, `readDirectory` and
`createDirectory`. Paths remain Strings. Directory entries carry a name and
nominal kind; enumeration returns direct children sorted by Unicode scalar
order, with no partial List on failure. Root links are resolved normally, while
child symlinks are classified without following them. Creation accepts an
existing directory and creates one missing level, subject to OS permission
inheritance. `IoOperation` has eight variants, including the three additions.

Lexical joining preserves dot components and path spelling. It does not resolve
links or enforce filesystem containment. The [directory converter](../examples/directory-converter/README.md)
demonstrates explicit traversal and documents independent-output assumptions,
reruns and partial effects. Existing output aliases can redirect writes.

Expected I/O errors remain Result values. Owned resources are released within
the operation. Native scratch mmap EINVAL is an internal inconsistency, while
ENOMEM retains allocation-failed; the Machine verifier tracks internal-failure
latch paths independently. Detected native test-child internal failures reach
the parent through private status 123 and event protocol v3. Image ABI v6 and
public exit classifications are unchanged.

The [42-condition ledger](v0.13.0-conformance.md), [10 internal gates](v0.13.0-internals.md),
[implementation record](v0.13.0.md) and [review corrections](v0.13.0-review.md)
record executable coverage and evidence limits. Inherited arguments, text I/O,
language tests, signal handling and GC remain covered by the cumulative gate.

## Distribution and limits

Use the tagged source archives and the real compiler `bin` directory on PATH
as described in [usage](../README.md). Other hosts/targets and prebuilt compiler
packages are not validated. Binary I/O, public File/Path handles, recursive
filesystem mutation, link-identity safety checks, defer and atomic file writes
remain outside this increment. Backwards compatibility is not guaranteed before
v1.0.0; exhaustive IoOperation matches must cover the added variants.

Controlled syscall/allocation injections do not prove recovery from every
physical memory-exhaustion scenario or arbitrary corruption. External kills,
concurrent filesystem replacement, power-loss durability, throughput and RSS
are not certified. Infinite tests have no built-in timeout. Existing collector
complexity limits remain unchanged.
