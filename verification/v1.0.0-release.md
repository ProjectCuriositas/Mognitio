# Mognitio v1.0.0 release validation

## Scope

The first stable release retains the v0.15.1 language, runtime, CLI, LSP and
Linux distribution contracts. No language feature or runtime behavior is
changed by this release preparation. Lévi supplies the integrated consumer:
configuration, arguments, directory traversal, file and text processing,
collections, user-defined types, error handling, modules and language tests.
Its generated native executable runs without the compiler, source or helpers.

The preflight used the unchanged Lévi v0.0.1 source at
`d18140b` and compiler main `f7c16b6`. It passed 182 observation records,
20 named language tests, 37 acceptance conditions, 12 design checks,
24 measurement cells (120 native samples), and 11 observer negative controls.
The final release notes must record fresh results with the exact 1.0.0 source
and frozen payload. Preflight results alone do not establish final acceptance.

## Final gates

Run the full Lisp suite, protocol/resource/token/projection checks, installer
recovery and failure checks, signing/trust tests and packaging permission tests.
The trust harness selects the package version from the frozen manifest instead
of assuming the initial 0.15.0 filename.

Follow the inherited [frozen artifact and signing procedure](v0.15.0-release.md).
Build once from the clean, fixed main commit with the pinned runtime inputs.
Verify Debian and offline payload byte equality, identities, checksums and the
production signature before publishing. On Ubuntu 24.04 and 26.04, check root
package installation followed by unrelated non-root execution, upgrades,
reinstallation, removal, and public APT delivery. Userland tests share a kernel.

Re-run Lévi acceptance and observer negative controls against the final source;
also build/test the source archive and compare golden HTML using the frozen
payload, including an isolated standalone executable. Record exact source
revisions and immutable asset digests in the GitHub Release notes.

The independently versioned VS Code extension requires an explicit 1.0.0
compatibility update and installed-VSIX integration verification. The old 0.1.0
VSIX rejects 1.0.0 and must not be presented as compatible or bundled here.
Track the compatible extension and its publication separately.

## Limits

Linux amd64 and the two stated Ubuntu userlands are the verified targets.
The consumer is a minimal static site generator, without HTTP, templates,
recursive input or watch mode. Existing scalar-processing allocation overhead
remains; no input-size, memory or execution-time guarantee is added.
Self-hosting, macros, reflection, REPL, MCP and later framework features are
outside this stable increment. A release number does not verify those features.
