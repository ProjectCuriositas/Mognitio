## Behavior

`String->scalars()` produces ordinary one-scalar Strings in a persistent List.
`List<String>->join(separator)` produces one flat String. A monotonic UTF-8 cursor
and two reverse-chain passes avoid repeated scalar indexing and prefix copying.
Native length additions check overflow before publishing the new accumulator;
the existing allocator separately checks physical size. Symbolic `List<T>` does
not acquire `join` from a later String-only specialization.

`IoError` requires a fourth field, the ordinary nominal `IoErrorPhase` Sum.
Both backends preserve the selected primary phase through cleanup. File final
release failures use `Cleanup`; standard stream scratch-release errors use
`Body`. Borrowed descriptors remain open. InvalidEncoding survives a secondary
release error, while invalid owned cleanup state follows the internal terminal.
The existing standard catalog is extended; no package loader is introduced.

Native helpers publish transient scalar/partial-List roots before allocation.
The I/O cleanup implementation reuses validated owned-record cleanup, returning
the ordinary errno separately from an internal-failure latch. An independent
zero/nonzero CFG check rejects a latch branch that would permit normal return.
The context ABI remains v6 and the test protocol remains v3.

## Structural and resource observations

For 64 / 128 / 256 Japanese scalars with a four-byte separator, both backends
observe n scalar visits and 3n scalar-copy bytes. Join observes n nodes per pass
and 3n + 4(n-1) copied bytes. CL additionally counts one output allocation.
Native counters increment at actual byte stores and node-processing sites;
normal artifacts contain none of those counters. Static allocation/copy-region
checks and scalar/fragment fixtures complement these bounded observations.

Ten scalar/join roundtrips are measured per native artifact. The independent
resource adapter records existing allocator/collector context counters after
the program returns. Compilation and source generation are outside timing.

not a speed comparison. Reverse-chain collector scanning remains an inherited
cost, separate from the helpers' linear structural bounds.

## Limits

The escaping fixture compares old slice/concat and new scalars/join source for
n, 2n and 4n, varying escaping density, Unicode, NUL and line endings. It is a
reproducible consumer-shaped fixture, not evidence that an external application
has migrated or that its issues are resolved. No full application throughput
or GC-inclusive linear-time claim is made.

Checks are specific to Linux amd64. Injected syscall outcomes establish the
classification path; they do not promise natural occurrence of every injected
errno or recovery from arbitrary corruption, process kills or physical OOM.
No new filesystem snapshot, rollback, durability or TOCTOU guarantee is added.
