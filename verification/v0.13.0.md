Date: 2026-10-02. Source revision: `7b3f1c965ecab34e73a9c180014915099db99320`.
This records the directory increment on the version branch, starting from
v0.12.0 commit `2b940c5a8e3e74e405a9fd1b68a94b7dae9478e2`.
Main integration, an immutable tag and a GitHub Release are separate operations.

## Implemented behavior

`Std\Io` adds three ordinary Function values: lexical `joinPath`, direct-child
`readDirectory` and single-level `createDirectory`. `DirectoryEntry` carries a
name and nominal `DirectoryEntryKind`; `IoOperation` now has eight variants.
The catalog, independent catalog/Core checks, Common Lisp backend, native
helpers and encoded-image checks all recognize the new operations and types.

Directory names are decoded strictly from raw bytes, classified without
following child links and sorted by Unicode scalar order. A duplicate name
keeps its first observation; distinct hardlink names remain distinct entries.
Enumeration either returns the complete List or an error. The error subject
identifies a decoded child when its metadata lookup fails, and the original
root when enumeration, decoding or cleanup fails. Directory creation follows
existing directory links and uses mode 0777 subject to inherited OS policy.

Native staging uses three owned records for path/scan/fd, rows and raw names.
Owned descriptors are closed before sorting and managed value construction;
raw mappings remain registered until they are released. Primary language
failures survive cleanup failures. Both the Common Lisp storage-failure path
and native allocation-failure path are exercised with a secondary internal
cleanup error. The image ABI remains v6.

Detected internal child failures use private status 123 and event protocol v3.
The parent waits for reap and event EOF, preserves committed results and prior
command failures, and interrupts the current attempt without starting later
tests. Ordinary main status 123, plain abnormal child status 3 and private
transport status 124 retain their distinct meanings.

The [directory converter](../examples/directory-converter/README.md) demonstrates
explicit queued traversal. Its fixtures satisfy the documented independent
output-target assumptions; the API does not enforce filesystem containment.

## Resource and failure evidence

Host and native fixtures begin with independent filesystem trees. Real checks
cover invalid raw UTF-8, permissions, root/child links, FIFOs, sockets, long
paths, 1,700-entry enumeration, hardlinks, umask, default ACL, setgid and GID
inheritance. The ACL and different-group cases are required, not skipped.
The reference program is exercised through both backends, language tests and
a native artifact after its source/manifest are removed and PATH is unavailable.

Controlled syscall results distinguish external errors from impossible owned
state. EINTR retries proceed to actual syscalls; synthetic close errors follow
a real close. Raw-record mutations cover size, alignment, bounds, terminators,
encoding and deliberately misleading d_type. Allocation and map-growth probes
exercise old/new ownership and cleanup before terminal diagnostics. Independent
Machine and encoded-byte mutations check roots, frame/register effects,
ownership transitions, terminal paths and event headers.

Real directory faults reach the test runner in initializer and test-body
contexts. Synthetic child fixtures separately cover pre-ready termination,
partial or contradictory event streams, version mismatch and status mapping.
The version-pair boundary uses independent v2 wire/reader fixtures, not a second
installed compiler. Primary/secondary reporting faults preserve the command
status and committed ledger according to their order.

## Limits

Validation is specific to Linux amd64. Controlled faults do not establish
recovery from every physical OOM, process kill or arbitrary memory corruption.
Malformed ownership fixtures avoid unsafe cleanup syscalls; an unrecoverable
mapping is left to isolated process teardown. Concurrent filesystem replacement,
power-loss durability, throughput and peak RSS are not certified. Directory
operations provide neither an atomic filesystem snapshot nor rollback of prior
successful effects.
