## Language and execution

Multiple `.mgn` modules in one project compile into one executable. The strict
`mognitio.toml` schema selects `src/<project-name>.mgn`; that module declares
its own `let main: Function(): Unit`. Normal run/native execution is silent.
Namespaces, brace-group imports, aliases, public declarations, and named witness
evidence provide explicit file boundaries. All modules are statically checked;
only reachable modules initialize, once, in deterministic dependency order.

Source discovery rejects symlinks, duplicate physical inputs, invalid UTF-8 paths,
and non-directory special `.mgn` files before reading. Publication protects all
inputs and future sources. The old single-source command is not retained.
Use `mgn` through the real compiler `bin` directory on PATH as described in the
[repository instructions](../README.md).

[Implementation verification](v0.10.0.md) records the review outcomes and limits.
[Test coverage](../tests/README.md) distinguishes public project cases from
internal Boolean kernel oracles. Public examples use the Unit project entry.
Cross-module closures and hidden contract values are tested under small-heap
GC stress; source/proof/publication faults and deterministic relocation are covered.

## Distribution and limits

Use the tagged source archives. Other hosts/targets and prebuilt compiler packages
are not validated. Registries, external dependencies, and separate compilation
are outside this release. The shared signature walker is not an independent
second algorithm; source type records and module provenance are verified separately.
Finite tests do not certify every input, unbounded resources, concurrent filesystem
replacement, forced termination, or power-loss durability. Existing collector
complexity limits remain unchanged.
