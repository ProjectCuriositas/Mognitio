# v0.14.0 release validation

Date: 2026-10-04

The v0.14.0 specification, design and implementation are accepted for release.
This is a source release for Linux amd64; no prebuilt compiler is distributed.
The compiler host requires glibc 2.34+, SBCL, ASDF, UIOP and SB-POSIX.
Ordinary generated ELF executables need neither SBCL nor libc.

## Changes and compatibility

`String->scalars()` returns ordinary length-one Strings in Unicode scalar order.
`List<String>->join(separator: String)` assembles text with separators only
between elements. Both preserve source text exactly and perform linear
structural work; allocator and collector costs are separate.

`Std\Io` adds `IoErrorPhase` with Input, Target, Body and Cleanup. Every
`IoError` now requires a phase field. Standard stream failures use Body.
A missing directory is a creation candidate only when ReadDirectory returns
Target / NotFound for the requested subject. Body or Cleanup failures must not
be interpreted as an absent or empty directory.

The [review corrections](v0.14.0-review.md) preserve first-file-close internal
failures through remaining cleanup, verify scalar root lifetime across native
control flow, and reject guards that overwrite an established primary outcome.
The [implementation record](v0.14.0.md) and [39-condition ledger](v0.14.0-conformance.md)
record coverage and limits. ABI v6 and test protocol v3 remain unchanged.

## Distribution and limits

Use the tagged source archive and the checkout's real bin directory on PATH,
as described in [usage](../README.md). No new library distribution system,
public fixture/process API, Char, general Iterator or mutable builder is added.
Binary I/O, public File/Path handles, recursive filesystem mutation, defer and
atomic writes remain outside this increment. Compatibility is not guaranteed
before v1.0.0; existing IoError constructors must supply the phase.

External application adoption and whole-application performance remain
unverified. Controlled fault injection does not certify physical exhaustion,
arbitrary corruption, concurrent filesystem replacement or power-loss recovery.
Other hosts/targets, throughput and RSS are not certified. Infinite tests have
no built-in timeout; existing collector complexity limits remain unchanged.
