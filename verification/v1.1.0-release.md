# Mognitio v1.1.0 release validation

## Accepted implementation

The [implementation record](v1.1.0.md) and [resume review](v1.1.0-resume-review.md)
cover the native free-list allocator, bounded marking worklist, independent
membership index, reference workloads, complete result observation and
measurement provenance. Existing 1.x language APIs and value semantics remain
supported. The fixed 74-cell performance acceptance retains its original
artifacts, environment and numerical profile; it is not an all-input guarantee.

## Release gates

Run the full source suite and checksum manifest from the fixed release candidate.
Validate the candidate and tagged source archives with the documented examples.
Build the formal toolchain once from clean main using the locked Ubuntu 24.04
runtime, core, notice and image identity. Keep those payload and package bytes
unchanged through validation and publication.

Follow the [frozen artifact/signing procedure](v0.15.0-release.md) for the compiler
and LSP. Run analysis, protocol, resource, token, projection, installer ownership,
recovery/failure, signing, trust and package-permission checks. Compare the exact
Debian and offline payload bytes, modes and build identities. Check offline
upgrades from the published 1.0.0 bundle on both supported Ubuntu userlands.

Verify the signed packages on Ubuntu 24.04 and 26.04 with root installation and
subsequent unrelated non-root run/build/test/LSP execution. Preserve the inherited
0.15.0 upgrade control and also validate the normal 1.0.0 upgrade through public
APT. Independently download and verify the frozen manifest, production signature
and asset hashes before publication. Record exact commits, hashes and workflow
results in the release notes.

Check the unchanged Lévi consumer with the final frozen payload, including its
language tests, golden output and isolated native execution. The existing
conformance and performance evidence remains tied to its original measured
artifacts; a fresh package smoke test does not replace that record.

Create the immutable version tag and the release snapshot branch
`mognitio/v110` at the same verified main commit. The snapshot branch preserves
the release point; ongoing integration continues through main.

## Distribution boundaries

Only Linux amd64 on Ubuntu 24.04 and 26.04 is in the distribution matrix.
Userland tests share a host kernel. Larger-input and remaining allocator/GC
costs are described in the implementation record, not hidden by the version bump.

The independently versioned VS Code extension 0.1.1 rejects a 1.1.0 server.
Do not bundle it or claim editor compatibility. Updating and publishing that
client is separate work. No Lévi release or dependency update is implied.
