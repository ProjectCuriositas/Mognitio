The ordinary I/O helper uses an explicit ownership chain separate from GC roots.
Its raw fd/staging/path fields cannot become managed roots. Independent machine
verification checks the actual helper instructions, frame accesses, callee-save
effects, root publication, cleanup unlinking and runtime-failure bridges.
The encoded ABI-v6 context record independently pins field offsets, sizes,
classifications and initial zero state for normal and test profiles.

The resource-failure tests establish cleanup before reporting, not merely that
the OS closes descriptors at process exit. Native close-failure fixtures execute
close first; injection does not manufacture a leak by omitting the syscall.
Actual RLIMIT_FSIZE tests remain separate from injected errno classification.

Host signal actions use Linux amd64's 32-byte rt_sigaction structure, including
the 64-bit kernel signal mask. This preserves a custom restorer without libc
rewriting it. The syscall argument sizes and SIGPIPE/SIGXFSZ identities are also
observed in native strace output. See [sigaction(2)](https://man7.org/linux/man-pages/man2/sigaction.2.html)
for the libc/kernel boundary and [getrlimit(2)](https://man7.org/linux/man-pages/man2/getrlimit.2.html)
for file-size signals.

Fault controls are private Lisp bindings, test-only helper replacements or the
external syscall tracer. No source API, installed CLI option or environment
variable enables fault injection. Tests require the facilities they exercise;
missing trace/ACL support causes failure instead of a passing skip.
